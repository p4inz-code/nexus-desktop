Honest about limits

What Nexus does not do

  • No cloud sync, no server and no account system.
  • No code signing yet, so Windows SmartScreen will warn you on first run.
  • No macOS, Linux or mobile version. Windows only.
  • No independent security audit yet. The code is closed source.

Getting started

Three steps

  1. Create a vault. Choose a master password and write down your recovery phrase.
  2. Add your files. Drag them in, or use Import. Nexus encrypts them as they arrive.
  3. Lock it. Close the vault, or let auto-lock do it. Your files are unreadable until you unlock again.

Questions

Before you download

Does it need the internet?

No. Encryption, decryption and license-key checks all happen on your PC. The only network call is an optional check for new releases, which talks to GitHub only and which you can switch off in Settings.

What if I forget my master password?

Use the recovery phrase you wrote down at setup. If you lose both, nobody can recover your vault, including us. That is by design, and there is no cloud password reset.

Is Nexus open source?

No. Nexus is closed source. The GitHub page hosts the downloads, the documentation and the issue tracker.

Why does Windows show a warning when I run it?

Nexus is not code-signed yet, so SmartScreen flags it like any new unsigned program. The download page explains how to check the file is the one we published before you run it.

What does it cost?

It is free during the public beta. A one-time lifetime license is planned for after the beta. See Pricing.
