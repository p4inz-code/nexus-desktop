Get Nexus for Windows

A single file, no installer. Requires Windows 10 or 11, 64-bit, and a beta license key.

Download from GitHub ReleasesAsk for a key

The button opens the latest release on GitHub. Download Nexus.exe and the matching Nexus.exe.sha256 file.

The newest release listed on GitHub may be older than the version we are testing. A newer build will be published there once testing is done. The known issues page lists what is fixed in development and not yet released.

Install

  1. Check the file. Use the checker below to confirm your copy matches the published hash.
  2. Run Nexus.exe. Windows will probably show a blue "Windows protected your PC" screen. Nexus is not code-signed yet, so this happens with any new unsigned program.
  3. Choose More info, then Run anyway. Only do this after the hash matches.
  4. Activate. Accept the license, enter your key, then set a master password and write down your recovery phrase.

Check your download

Select the file you downloaded. Your browser works out its SHA-256 hash locally and nothing is uploaded. Paste the hash from the release if you want the page to compare for you.

Choose the file to see its hash.

Or check it yourself

Get-FileHash .\Nexus.exe -Algorithm SHA256

Run that in PowerShell from the folder that holds the file.
